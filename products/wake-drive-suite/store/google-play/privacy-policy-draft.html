1. 카메라와 감지 정보

사용자가 감지를 시작하면 전면 카메라 영상과 얼굴·눈·고개 움직임을 기기 안에서 일시적으로 분석하여 졸음 의심 신호와 경고를 표시합니다. 영상, 사진 또는 음성을 녹화·녹음하지 않으며, 카메라 영상과 감지 신호를 운영자나 외부 서버로 전송하지 않습니다. 얼굴로 사용자의 신원을 식별하거나 얼굴 인증 정보를 등록하지 않습니다.

진행 중인 감지 상태와 시간 흐름은 화면 표시를 위해 기기 메모리에서 처리됩니다. 감지를 종료하면 카메라 사용을 종료합니다. 작은 창 기능을 사용하면 사용자가 보고 있는 작은 창에서 감지가 계속될 수 있습니다.

2. 위치·광고·이용 통계

앱은 GPS, 정밀·대략적 위치 또는 백그라운드 위치에 접근하지 않습니다. GPS 속도 표시도 제공하지 않습니다. 광고 및 분석 SDK를 포함하지 않으며 광고 ID와 사용 통계를 수집하거나 전송하지 않습니다. 앱에는 인터넷 권한이 없고, 감지 모델과 경고 영상이 설치 파일에 포함됩니다.

3. 기기에 저장하는 설정

언어, 경고 영상 선택, 소리·감지·작은 창 설정 및 안내 확인 여부 등 앱 사용 설정은 해당 기기의 앱 저장공간에 보관합니다. 회원가입이나 로그인이 없으며 운영자 서버와 동기화하지 않습니다. 이전 버전에서 저장된 설정은 업데이트 시 유지될 수 있지만 외부로 전송하지 않습니다.

4. 외부 제공 및 음성 안내

앱에서 처리한 영상·감지 신호·설정 데이터를 제3자에게 제공하거나 판매하지 않습니다. 음성 안내는 휴대폰에 설치된 오프라인 음성을 사용합니다. 해당 언어의 오프라인 음성이 없으면 음성 안내가 제한될 수 있으며 경고음과 화면 경고를 사용할 수 있습니다.

5. 권한과 삭제

감지 기능을 위해 카메라 권한이 필요하며, 사용자는 휴대폰 설정에서 허용하거나 철회할 수 있습니다. 카메라 권한을 허용하지 않으면 감지 기능을 사용할 수 없습니다. 작은 창 기능은 선택 사항이며 휴대폰의 PIP 설정에서 관리할 수 있습니다.

저장된 설정은 Android 설정 → 앱 → Wake Drive → 저장공간 → 데이터 삭제, 또는 앱 삭제로 지울 수 있습니다. 운영자 서버에 계정이나 저장된 카메라 데이터가 없으므로 별도의 서버 계정 삭제 절차는 없습니다.

사용자가 직접 이메일로 문의하면 이메일 주소, 문의 내용 및 직접 첨부한 파일이 고객지원 목적으로 처리됩니다. 문의 기록은 회사 공개 방침의 고객문의 보유 기준인 문의 처리 완료 후 3년에 따릅니다. 정책 링크는 외부 브라우저에서, 이메일 링크는 외부 메일 앱에서 열리며, 링크를 누르는 것만으로 앱의 카메라 영상이나 감지 기록을 전송하지 않습니다. 웹사이트 방문과 이메일 이용에는 해당 외부 서비스의 정보 처리가 별도로 적용될 수 있습니다.

6. 변경과 문의
