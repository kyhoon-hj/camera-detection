# Wake Drive 1.0.0 출시 준비 결과

2026-09-11 · Android versionCode 27 · com.hjsolution.jolbang · minSdk 24 / targetSdk 36

앱 수정, 실제 빌드, 휴대폰 업데이트를 완료했습니다. 현재 AAB는 **미서명 검토용**이며 Google Play 제출 완료 또는 심사 통과 상태가 아닙니다.

## 이번 버전

- GPS 속도, 위치 권한·조회·설정, Firebase Analytics와 AdMob SDK 및 광고 ID 권한을 제거했습니다.
- 인터넷 권한도 제거했습니다. 감지 모델과 한국어 10편·영어 2편 영상을 모두 앱에 포함했습니다. 영어 Rock Star 원본 파일도 유지했습니다.
- 광고 시청·잠금 해제 없이 모든 영상이 제공됩니다. 기존 영상 선택과 언어 설정을 유지합니다.
- 실시간 카메라는 작은 촬영 영역을 유지하고, 경고 영상에는 기존 전체화면·흰색 음영 디자인을 유지했습니다.
- 홈에서만 언어를 변경합니다. 감지 모드에는 언어·GPS·통계 설정이 없습니다.
- 앱 설정에 기기 내 처리와 삭제 방법을 설명하는 개인정보 안내를 추가했습니다. 음성 안내는 설치된 오프라인 음성을 사용합니다.

## 업로드 키와 서명 방법

Android Studio에서 `native/jolbang/android`를 열고 Build → Generate Signed App Bundle or APK → Android App Bundle → Create new로 업로드 키를 생성합니다. 키 경로는 프로젝트·outputs·공유 폴더 밖의 본인 전용 보관 위치로 지정하고 별도로 안전하게 백업합니다. 키 암호와 별칭은 본인이 관리합니다. 비밀번호를 채팅·소스·문서에 적지 않습니다.

키를 만든 뒤 PowerShell에서 프로젝트의 `Invoke-SignedRelease.ps1`을 실행하면 경로·별칭·비밀번호를 직접 입력할 수 있습니다. 비밀번호는 숨김 입력을 받으며 해당 빌드 프로세스에만 전달하고 종료 시 제거합니다. 스크립트는 공유 빌드 게이트를 사용합니다. 자동 키 생성은 하지 않습니다.

```powershell
Set-Location 'C:\Users\김영화\Documents\Codex\2026-09-11\c-users-documents-codex-2026-09\outputs\WakeDrive-Latest'
.\Invoke-SignedRelease.ps1
```

성공하면 `releases/wake-drive-1.0.0-release-signed.aab`와 `release-signed.apk`가 생성됩니다. 실제 서명 검증 후 해당 AAB를 사용합니다. 현재 signed 파일은 존재하지 않습니다.

적용한 [hj-app-builder 스킬](C:/Users/김영화/.agents/skills/hj-app-builder/SKILL.md)의 서명 지침은 “keystore가 없으면 안전한 생성 방법과 설정 구조만 준비한다.”입니다. 이에 따라 안전한 입력 스크립트와 Gradle 서명 구성을 준비했습니다.
