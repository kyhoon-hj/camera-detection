## 수정

기존 코드는 마지막 **분석에 사용한** 영상 시간과 현재 시간을 비교해 멈춤 시계를 갱신했다. 분석 사이에 영상이 일시정지되거나 사용 불가능한 프레임이 되면, 마지막 시간이 분석 시간과 다른 채 고정되어 매번 새 영상으로 잘못 판단할 수 있었다.

- `src/cameraPlayback.ts`: 프레임 관찰 시간을 분석 시간과 분리한다. 재생 가능하고 시간이 변한 프레임만 진행으로 인정한다.
- 일시정지된 미리보기에는 재생을 한 번 시도한다. 실패하거나 응답하지 않아도 멈춤 제한 시간을 연장하지 않는다. 실제 프레임 진행이 회복돼야 다음 복구 시도를 허용한다.
- 4초간 진행이 없으면 기존 오류 처리로 카메라를 종료하고 재시작 안내를 표시한다.
- 경고 동영상 재생 중 분석을 쉬는 기존 흐름을 유지한다. 경고 종료와 새 세션 시작 시 멈춤 시계를 초기화한다. 영어 팝업 경고 중에는 계속 분석한다.
- 새로운 Firebase 이벤트나 영상 업로드는 추가하지 않았다.
