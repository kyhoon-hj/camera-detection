# 홈 영상 잠금 — 2026-09-10

요청: 홈 영상을 잠금 상태로 표시하고 광고 영상을 시청해야 해제하되 기존 기본 프로세스를 유지.

## 동작

1. 기본 제공 `video-0`과 기존 보관함의 영상은 계속 해제 상태로 유지한다. 사용자 보관함/적용 정보는 초기화하지 않는다.
2. 미보유 영상은 자물쇠와 흐린 썸네일로 표시한다. 잠긴 썸네일 터치는 잠금 안내를 표시하며 미리보기 재생을 열지 않는다.
3. Android 앱의 `광고 보고 잠금 해제`는 기존 AdMob 보상형 광고 함수를 호출한다. 해당 영상 ID를 직접 전달해 다른 영상이 잘못 해제되지 않도록 한다.
4. 보상 확인 → 영상 다운로드/캐시 완료 → 기존 보관함 상태에 추가한다. 취소, 보상 없음, 다운로드 실패는 잠금을 유지한다. 진행 중 중복 요청과 홈 영상 선택/시작을 막는다.
5. 해제해도 현재 경고 영상은 변경하지 않는다. 사용자가 `이 영상으로 설정하기`를 누르면 기존 적용 절차를 실행한다. 미리보기, 감지 시작, 경고 영상 재생 흐름을 유지한다.
6. 웹의 기존 무광고 즉시 다운로드 우회는 졸방에서 차단한다. 웹 잠금 해제 요청에는 Android 앱 안내를 보여주고 잠금을 유지한다. 가짜 광고나 시청 보상은 생성하지 않는다. 열공 광고 함수/화면은 그대로 유지한다.

## 검증

- 기존 테스트와 새 잠금 흐름 5개 테스트: 총 107개 통과.
- 보상 전 다운로드 금지, 취소 시 해제 금지, 다운로드 실패 시 해제 금지, 해제 결과 저장/복원과 별도 적용, 기본 영상 광고 재요청 없음.
- 웹 브라우저: 기본 1편 해제/10편 잠금, 잠긴 썸네일 클릭 시 미리보기 미생성, 광고 해제 버튼의 웹 우회 차단, 가로 넘침 없음(390px).
- TypeScript/졸방 웹 빌드 및 Android APK 빌드. APK 웹 자산 대조는 `runtime-evidence.json` 참조.
- 실기기 AdMob 광고 재생/완료/중도 닫기는 이번에 실행하지 않음. 기존 개발용 AdMob 테스트 광고 설정을 사용하며 운영 광고 배포를 완료한 것은 아님.
