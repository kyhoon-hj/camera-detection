## 0.1.19 · 거치 위치 그림 수정

사용자 피드백: 기존 1번 거치 위치가 너무 낮고 핸들 기준 위치가 불분명했습니다. Stitch 수정 화면 `377b06e11a514e8ebecb8548fa718a97`([시안 HTML](design/stitch-placement-guide-v2.html), [PNG](design/stitch-placement-guide-v2.png))의 SVG를 적용했습니다.

메인 그림에 핸들·계기판·대시보드를 표시하고, 계기판 옆 상단과 오른쪽 상단의 두 위치를 모두 1번으로 표시합니다. 오른쪽은 점선 대안이며 두 대 설치를 뜻하지 않습니다. 핸들의 원형과 살을 보강하고 측면 카메라 높이를 얼굴 가까이 올렸습니다. 전면 카메라 방향과 얼굴 프레임 확인은 하단의 2·3번 그림으로 유지합니다. 숫자만 있는 SVG와 번역 가능한 캡션을 분리했습니다. ‘도로 시야와 계기판을 가리지 않게 설치’ 문구를 함께 표시합니다.

버튼·숨김 설정·측정 시작 동작은 0.1.18과 동일합니다. 기존 숨김 설정을 이미 선택한 사용자에게 강제로 다시 띄우지 않습니다.

## 표시·버튼 정책

1. 홈에서 졸음 감지 모드 진입 시 기존 메뉴 광고 절차 이후 표시합니다. 기존 긴 안전 안내 팝업을 교체해 팝업을 중복으로 띄우지 않습니다.
2. **확인**: 이번 안내만 닫고 기존 카메라 권한 확인·측정 시작 흐름을 실행합니다. 다음 모드 진입 때 다시 표시합니다.
3. **그만 보기**: 숨김 설정을 저장한 뒤 같은 시작 흐름을 실행합니다. 이후 모드 진입 시 안내를 건너뜁니다. 숨겨도 카메라 권한 확인은 생략하지 않습니다.
4. 저장 실패: 팝업을 유지하고 오류 문구를 표시합니다. 확인 버튼으로는 저장 없이 진행할 수 있습니다.
5. Android 뒤로가기 또는 Escape: 홈으로 돌아갑니다. 숨김 상태는 저장하지 않고 카메라도 시작하지 않습니다.
6. 주소/세션 복원으로 측정 화면에 바로 진입한 경우에도 시작 버튼에서 같은 안내 표시 조건을 확인합니다.

저장 키는 앱 범위가 적용된 `jolbang:driver-placement-guide.v1`, 숨김 값은 `hidden`입니다. 개인정보 첫 실행 안내 키와 분리되며 재설치 또는 앱 데이터 삭제 시 초기화됩니다. 개발 중 다시 보고 싶다면 이 키만 제거하세요. 한국어/영어를 바꿔도 숨김 설정은 공유합니다.

네이티브 배너는 안내 표시 중 숨깁니다. HTML modal dialog를 portal로 표시해 화면 밖 클릭을 막고 포커스가 팝업 안에 머물게 합니다. 확인 버튼을 초기 포커스로 두며 종료 시 이전 포커스를 복원합니다. 작은 화면·가로 모드에서는 팝업 자체가 스크롤됩니다.
