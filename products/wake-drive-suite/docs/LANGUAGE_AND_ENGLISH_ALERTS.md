# 한국어·영어와 영어 경고 방식

**0.1.23 최신 변경:** 언어 선택은 홈 화면 설정에서만 표시합니다. 감지 모드 내부에서는 준비 중이거나 감지를 종료했더라도 언어 항목을 표시하지 않습니다. 저장된 언어와 언어별 영상 정책은 유지됩니다. 아래 촬영 중 언어 변경 설명은 이전 버전 이력입니다.

**0.1.20 최신 변경:** 기존 앱 영어 모드에 `rock-star`(Rock Star)를 추가했습니다. 영어 목록은 Rest stop fairy와 Rock Star 2편, 한국어는 기존 10편입니다. 영어의 적용 영상과 보유 영상 랜덤 선택 모두 두 영상의 보유 상태를 따릅니다. 잠금 해제 없이 자동 재생하지 않습니다. 아래는 이전 버전 구현 이력입니다.

## 범위와 언어 선택

Wake Drive의 홈·설정·측정·안전·Analytics 동의·Android 권한/PiP 안내를 한국어/영어로 표시한다. 독립 열공 프로젝트에는 적용하지 않았다. 광고 소재, 영상에 포함된 자막·음성, OS 자체 권한 화면은 앱 번역 대상이 아니다.

- 저장된 선택이 없으면 단말의 주 언어가 `ko`인 경우 한국어, 그 외는 영어다. 보조 언어 목록의 한국어 여부는 사용하지 않는다.
- Android 단말 언어를 네이티브에서 읽고, 응답 실패 시 WebView의 `navigator.language`로 시작한다.
- 설정의 한국어/English 선택은 `jolbang:language.v1`에 저장한다. Android 권한 안내/PiP도 같은 선택을 따르도록 네이티브 설정에 동기화한다.
- 촬영·측정 중에도 설정에서 언어를 변경할 수 있다. 카메라, 측정 세션, 기준 위치를 유지한다. 준비(LOADING)·광고 처리 중에는 중간 작업 보호를 위해 잠시 비활성화한다.
- 언어 전환 시 재생 중인 경고와 테스트 팝업, 이전 언어 TTS를 닫고 다음 경고부터 새 언어를 적용한다. 이전 영상의 비동기 재생 실패가 새 경고에 영향을 주지 않도록 경고 세대 번호를 검사한다.
- 언어 전환으로 보유/적용 영상, 학습 기록, Analytics 동의를 초기화하지 않는다.

## 영어 경고

- 기본값은 **휴게소 안내요정 영상**이다. 이미 사용자가 명시적으로 저장한 POPUP 선택은 유지하며, 영상의 적용 버튼을 누르면 VIDEO로 전환한다. 눈 감김/고개 숙임의 기존 판정 기준은 유지한다.
- 영상을 아직 해제하지 않았다면 팝업 + 경고음을 사용한다. 설정에서 팝업만 사용하도록 선택할 수도 있다.
- 팝업 중 카메라 분석과 PiP heartbeat는 계속된다. 닫은 뒤 기존 경고 회복 절차를 따른다.
- 소리가 켜져 있으면 즉시 경고음을 내고 2.5초마다 반복한다. 경고 닫기·측정 종료 시 타이머를 해제한다. 기기 음량/무음 상태나 오디오 제한에 따라 실제 출력은 달라질 수 있다.
- 영어에서는 한국어 TTS를 호출하지 않는다. 홈/설정의 경고 테스트로 같은 팝업·경고음을 확인한다. 테스트는 실제 졸음 경고나 영상 재생 Analytics를 생성하지 않는다.
- 한국어에서는 기존 적용 영상/보유 영상 랜덤 재생과 한국어 음성 안내를 유지한다.

## 영어 영상: 사용자 지정 완료

0.1.17 / versionCode 18: 사용자 요청으로 한국어 모드에서는 `video-6` 휴게소 안내요정을 제외합니다. 한국어 보관함은 10편이며 보유 개수, 설정·촬영 화면의 적용 영상 표시, 단일/랜덤 경고 선택에도 같은 규칙을 적용합니다. 이전 적용 값이 `video-6`이면 한국어에서 사용 가능한 첫 보유 영상(보유 목록이 비정상이면 기본 `video-0`)으로 대체합니다. 저장된 보유·적용 기록은 삭제하지 않으며 영어 모드에서는 기존 광고로 해제한 요정을 계속 사용할 수 있습니다. `driverVideoProfiles`, `koreanDriverLibrary`, `chooseDriverWarning`과 언어 회귀 테스트를 함께 유지하세요.

2026-09-11 사용자가 영어 모드에 **휴게소 안내요정**만 사용하도록 지정했다. `src/driverWarning.ts`의 `VERIFIED_ENGLISH_VIDEO_IDS`는 `['video-6']`이다. 영상 파일은 `public/media/drowsy-video-6.mp4`, 영어 표시명은 **Rest stop fairy**다. 이번 지정의 근거는 사용자 요청이며 별도 음성 전수 청취 검증을 의미하지 않는다.

영어 보관함·선택 포스터·측정 화면 경고 영상에는 이 한 편만 표시한다. 한국어에서 다른 영상이 적용돼 있거나 보유 영상 랜덤 재생이 설정돼 있어도 영어의 VIDEO 모드에서는 보유한 `video-6`만 재생한다. 단순 언어 변경은 한국어 적용 영상 설정을 바꾸지 않는다.

잠금 해제는 기존 광고 보상 절차를 따른다. 보유 목록에 `video-6`이 없으면 자동으로 무료 해제하지 않는다. 이때 VIDEO 설정이어도 팝업·경고음으로 대체하며 보관함에 잠금 해제 버튼을 제공한다.

## 코드와 Analytics

- `src/language.ts`: 언어 결정·저장·구독·문자열 변환.
- `src/english.ts`: 한국어 원문을 키로 사용하는 영문 사전. `{0}` 등의 치환 인덱스를 유지한다.
- `src/driverWarning.ts`: 언어별 경고 선택과 영어 영상 허용 목록.
- `src/DriverWarningPopup.tsx`: 팝업 및 반복 타이머 정리.
- 팝업은 기존 `drive_warning`의 `reason`을 기록하고 `video_id`는 보내지 않는다. 실제 영상이 없어 `video_play_start/complete`도 생성하지 않는다. `video_id`가 있는 경고만 집계하면 팝업 경고가 누락된다.
- 언어 선택을 새 Analytics 이벤트/속성으로 추가하지 않았다.
