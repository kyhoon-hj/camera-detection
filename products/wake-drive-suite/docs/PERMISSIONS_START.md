# 시작 반응 및 권한 복구

| 단계 | 변경 | 완료 기준 |
|---|---|---|
| 시작 | 안내 확인 후 바로 시작, 소리·화면 유지가 카메라 시작을 무기한 막지 않음 | 준비 단계·오류가 버튼 근처에 표시 |
| 권한 | Android 카메라·선택 위치·PiP 실제 상태와 설정 이동 | 앱 실행/설정 복귀 시 필수 권한 안내, 필요 기능 시 선택 권한 안내 |
| 검증 | 빌드·회귀·휴대폰 | 구현과 실행 검증 범위를 구분 |

카메라는 필수, 위치는 GPS 속도를 선택할 때, PiP는 작은 화면을 선택할 때 필요한 권한이다. 마이크·연락처 등 사용하지 않는 권한은 요청하지 않는다. 휴대폰 전역 카메라 토글은 일반 앱의 공개 API로 활성 상태를 조회할 수 없으므로 꺼졌다고 추측하지 않으며 권한 메뉴에서 개인정보 설정으로 이동해 확인하도록 안내한다.

공식 근거: https://developer.android.com/reference/android/provider/Settings#ACTION_APPLICATION_DETAILS_SETTINGS, https://developer.android.com/reference/android/hardware/SensorPrivacyManager (공개 API는 지원 여부 확인).

## 구현

- 안전 안내의 ‘확인하고 시작’은 안내창을 닫은 뒤 실제 시작 함수를 호출한다. 이전에는 안내 확인만 처리했다.
- 소리 준비와 화면 켜짐 유지 요청이 끝날 때까지 카메라 시작을 기다리지 않는다. 카메라 연결·영상 준비·분석 준비 단계를 버튼 근처에 표시한다. 요청 실패나 제한 시간 초과는 오류와 재시도로 이어진다.
- Android 앱 실행과 설정 복귀 시 카메라 권한을 검사한다. 꺼져 있으면 네이티브 팝업의 ‘설정으로 이동’으로 해당 앱 설정을 연다. 허용 여부는 사용자가 설정에서 직접 변경한다.
- GPS 속도 및 작은 화면 사용 시 필요한 선택 권한을 검사한다. 설정 화면의 ‘권한 확인 및 설정’에서 카메라·위치 권한·위치 기능·화면 속 화면 상태와 설정 바로가기를 제공한다.
- 기존 광고 영역, 영상 보상 잠금 해제·보유·적용 과정, 스크롤되는 시작 버튼 배치를 유지한다.

## 검증 기록 (2026-09-10, 0.1.5 / versionCode 6)

- TypeScript, 웹 빌드, Android 앱 및 계측 테스트 APK 빌드 통과.
- 회귀 테스트: 18개 파일, 126개 테스트 통과. 권한 거절 메시지, 준비 시간 초과, 늦게 반환된 카메라 트랙 해제 포함.
- SM-F711N에 기존 설치를 유지하는 업데이트 설치 성공. 설치 버전 0.1.5 / 6 및 원래 카메라 권한 허용 상태 복원 확인.
- 미리보기 서버 5210/5211 재실행 후 HTTP 성공, 드라이버 웹/APK 파일 해시 일치 확인. 상세 기록은 runtime-evidence.json.
- **실제 버튼·카메라·설정 이동 검증은 대기 중**: 첫 권한 팝업 계측 테스트에서 텍스트를 찾지 못했으며, OS 상태 확인 결과 휴대폰 잠금 화면(showing=true, interactiveState=SLEEP)이었다. 잠금 해제를 요청했고, 검증을 통과했다고 간주하지 않는다. 테스트에는 잠금 상태 사전 검사와 테스트 중 화면 유지 처리를 추가했다.
- 재개 시 StartupPermissionsIntegrationTest의 권한 거절·설정 이동 테스트와 카메라 시작·종료·재시작 테스트를 실행한다. 권한 거절 테스트 전후 실제 사용자의 권한을 복원해야 한다. 촬영 화면은 저장하지 않는다. PiP 카메라 연속성 및 사람의 졸음 감지 정확도는 이 검증 범위에 포함하지 않는다.
