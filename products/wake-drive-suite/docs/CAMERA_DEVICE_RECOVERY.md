# 카메라 활성화 복구 · 0.1.22

2026-09-11. 경고 영상 전체화면 변경 뒤 카메라가 안 나온다는 신고를 확인했습니다.

브라우저의 카메라 영상은 재생 상태이며 1280×720 프레임과 재생 시간이 진행됐으나, 영상 내용은 카메라 꺼짐 아이콘이었습니다. PC에는 Mirametrix Virtual Camera, IR camera, USB webcam이 함께 등록돼 있었습니다.

기본 스트림이 가상/IR/깊이 장치이면 권한 승인 후 확인된 장치 목록에서 실제 웹캠을 찾아 명시적인 deviceId로 연결하도록 수정했습니다. 교체 전 스트림을 종료하며, 실제 웹캠 연결 실패는 오류로 전달합니다. 이미 정상 전면 카메라를 사용하거나 사용자가 명시적으로 장치를 지정한 경우에는 교체하지 않습니다. 이름을 확인할 수 없거나 대체 카메라가 없으면 기존 스트림을 유지합니다.

실행 중인 5220 앱에 반영한 뒤 장치 이름이 USB webcam (0408:50c3)로 표시됐고, 꺼짐 아이콘 대신 실제 주변 영상이 표시됨을 브라우저에서 확인했습니다. 얼굴이 프레임에 없어 기준 측정 대기 상태였습니다. 얼굴 인식 완료 또는 졸음 경고 판정 성공으로 기록하지 않습니다. 카메라 스크린샷은 프로젝트 파일로 저장하지 않았습니다.

자동 검증은 가상 카메라→RGB 선택, 기존 트랙 종료, IR 제외, 정상 전면 카메라/명시적 선택 유지, 실제 웹캠 연결 실패 전달을 포함합니다. 전체 웹 테스트 184개가 통과했습니다.
