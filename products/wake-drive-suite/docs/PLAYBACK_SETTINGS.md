# 경고 영상 재생 방식

2026-09-10 요청: 설정에서 현재 적용 영상만/보유 영상 랜덤을 선택하고 광고 제거 옵션 삭제.

| 단계 | 구현 범위 | 파일 | 완료 기준 |
|---|---|---|---|
| 1 | 재생 방식 저장·선택 | wakeUpPlayback, main | 기존 설치 기본값 단일, 랜덤은 보유 영상만 |
| 2 | 설정·홈·현재 재생 표시 | main, DriverLibrary, driver-effects | 두 옵션 선택, 광고 제거 항목 없음 |
| 3 | 회귀·빌드·화면 검증 | tests, docs | 웹·Android 및 재시작 유지 확인 |

- 기본값은 **현재 적용 영상만**. 기존 보유 목록과 적용 영상은 유지.
- **보유 영상 랜덤**은 경고가 시작되는 시점마다 보유 목록에서 한 편 선택. 같은 영상이 연속 선택될 수도 있음. 1편만 보유하면 그 영상 재생.
- 선택 결과는 해당 경고 재생 동안 고정. 자동 재생 실패 후 재시도해도 다시 추첨하지 않음. 재생 중 카드에는 실제 선택된 영상의 이름·이미지 표시.
- 모드는 졸방의 별도 저장 키에 보관하고 재실행 시 복원. 감지 중·카메라 준비 중·영상 다운로드 중에는 설정 변경 비활성화.
- 홈에서 보유 영상을 직접 ‘이 영상으로 설정하기’ 하면 단일 모드로 전환. 랜덤 모드일 때 이 동작을 홈에 안내.
- 설정 화면의 광고 제거 구매 항목 삭제. 기존 광고 시청 잠금 해제 절차는 유지.

## 검증 결과

- 16개 파일, 120개 테스트 통과. 보유 영상만 추첨, 단일 모드 고정, 1편 보유, 손상된 적용 값 복구, 경고마다 선택 검증.
- TypeScript·졸방 웹 빌드·Android assembleDebug 성공. 웹/APK 자산 비교는 `runtime-evidence.json` 참조.
- 390×844 브라우저에서 두 옵션 선택 표시, 랜덤 선택 후 새로고침 유지, 홈 직접 적용 시 단일 모드 전환, 광고 제거 항목 없음 확인.
- 실기기 카메라로 경고를 발생시켜 랜덤 영상을 재생하는 동작과 실제 광고 보상은 이번 검증에서 실행하지 않음.
