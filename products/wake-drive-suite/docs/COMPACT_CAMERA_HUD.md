# 카메라 속도·시간 표시 최소화

2026-09-10, Wake Drive 0.1.6 / versionCode 7.

- 넓은 하단 그라데이션, 큰 카드, 카드 장식과 반복 설명을 제거했다.
- 실제 GPS 속도와 경과 시간은 유지하고, 카메라 하단 양쪽 가장자리에 작은 반투명 표시로 배치했다. 속도 숫자 22px, 시간 숫자 18px; 가로에서는 각각 20px, 17px.
- GPS 사용 버튼은 카메라 밖 상태 영역으로 이동했다. 기존 GPS 권한 검사와 설정 흐름은 유지한다.
- GPS 꺼짐·미측정은 계속 대시로 표시하며 임의 속도를 표시하지 않는다. 상세 상태는 접근성 이름과 툴팁으로 제공한다. PiP와 경고 영상에서는 기존처럼 HUD를 숨긴다.

- 320×740: 양쪽 표시 사이 38.1px, 가로 문서 넘침 없음.
- 844×390: HUD 최대 높이 31.3px, 양쪽 표시 사이 193.8px.
- GPS 사용 버튼이 카메라 DOM 바깥에 있는 것을 확인했다. 세로·가로 스크린샷을 확인했다.
- 이 검증은 준비 화면의 실제 레이아웃 검증이며 사람의 졸음 감지 정확도나 실제 GPS 속도 검증은 아니다. 기존 0.1.5 권한·카메라 실기 대기 기록은 PERMISSIONS_START.md에 유지한다.

- TypeScript·웹·Android 빌드 통과. 연결된 SM-F711N 업데이트 설치 성공 및 0.1.6 / versionCode 7 확인. 설치본의 실제 카메라 화면 검증은 별도이며, 위 화면 크기 수치는 웹 미리보기에서 측정했다.
