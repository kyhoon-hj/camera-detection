# 경고 영상 재생 점검

2026-09-10, 0.1.7 / versionCode 8.

## 확인 및 수정

- 사용자 신고는 졸음 감지 후 경고 영상이다. 실제 휴대폰은 잠금(showing=true, interactiveState=SLEEP) 상태여서 해당 증상을 직접 재현하지 못했다. 정확한 실패 단계에 대한 추가 질문은 대기 중이다.
- 웹에서 검증용 카메라 스트림과 졸음 입력을 주입해 실제 앱의 감지 결과 처리→영상 선택→경고 표시→MP4 재생 경로를 실행했다. overlay opacity=1, 실제 MP4 currentTime=7.32초, paused=false를 확인했다. 이는 실제 사람의 얼굴 감지 검증이 아니다.
- 영상 play Promise가 끝나지 않으면 감지 처리가 중단된 채 native watchdog의 8초 종료에 도달할 수 있었다. 재생 시작을 3초로 제한하고 실패 시 경고 영상 상태를 해제해 감지를 재개하며 소리·음성 경고를 시도하도록 보완했다. 오래된 세션의 비동기 실패가 새 세션을 종료하지 않도록 세션 번호를 검사한다.
- 기존 onError의 오류 문구는 다음 감지 프레임에서 지워졌다. 별도 오류 상태로 보관해 사용자가 확인할 때까지 표시한다. 숨겨진 영상의 사전 로딩 오류는 진행 중인 경고가 아니면 무시한다.
- 부수적으로 홈 미리보기의 투명한 창 문제를 재현했다. 부모 motion-paused가 창 등장 애니메이션까지 멈춰 opacity=0에 머물렀다. 미리보기 창과 배경은 등장 애니메이션을 완료하도록 예외 처리했다. 수정 후 opacity=1, currentTime=9.02초, paused=false 및 화면을 확인했다.
- 기존 2초 감지 2회 또는 4초 지속의 영상 전환 조건과 보유·랜덤 영상 선택 정책은 변경하지 않았다.

## 검증

- 재생 Promise가 응답하지 않는 오류를 검증용 페이지에서 강제로 주입한 후 약 26초 시점에 runState=running, 카메라 시간 25.87초, 오류 문구 유지, 경고 overlay 해제를 확인했다. 검증용 입력은 새로고침·원래 미리보기 복귀로 제거했다.
- TypeScript 통과, 회귀 18개 파일 126개 테스트 통과.
- 실제 설치본의 WebView 재생·실제 졸음 신호 재현 및 Android 소리 출력은 아직 미검증이다. 잠금을 해제한 휴대폰에서 후속 확인이 필요하다.

- Android 0.1.7 / versionCode 8 업데이트 설치 성공. 웹/APK 파일 일치 확인.
- SM-F711N 실기 BundledVideoDecodeTest 통과(OK 1 test): 내장 경고 영상 11편 모두 MediaMetadataRetriever로 길이 및 첫 프레임 디코딩 성공. 테스트용 임시 복사본 삭제 확인. 이는 잠금 해제 없이 실행하는 파일·디코더 검사이며 WebView 재생이나 졸음 자동 전환 실기 성공을 뜻하지 않는다.
