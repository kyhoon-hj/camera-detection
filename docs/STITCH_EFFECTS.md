원본의 네온 라임·핑크·시안, 점무늬, 둥근 카드, 스티커와 눌림 효과를 사용한다. 원본의 예시 속도·안전 점수·가상 하드웨어 기능은 실제 기능으로 표시하지 않는다. 촬영 대신 샘플 운전자 사진을 표시하지 않는다.

광고 완료 → 영상 준비 → 보관함 추가 → 사용자 직접 적용 절차와 감지 임계값을 유지한다. 대기 화면 효과는 짧게 끝나고 감지 중에는 장식이 반복 움직이지 않는다. `prefers-reduced-motion`에서는 장식 애니메이션·전환을 끈다.

## 반영 결과

- 기존 경고 영상 11편의 1.2초 대표 프레임을 WebP로 추출해 `public/posters/`에 포함(총 약 314 KB). 원본 동영상은 그대로 보존. 목록을 보기 위해 12개 video 요소를 초기화하던 방식을 정적 이미지와 지연 로딩으로 교체.
- 잠긴 영상은 이미지 흐림·어두움·점무늬와 잠금 버튼으로 표시. 미리보기와 직접 적용은 기존 보유 조건을 유지. 이미지 로딩 실패 시 대체 문구 표시.
- 홈 점무늬와 별 장식, 선택 스티커 등장, 180ms 버튼 눌림, 250ms 미리보기 등장 효과. 반복 장식 대신 한 번의 짧은 움직임 사용.
- 카메라 화면의 라임·시안 계기판, 촬영 모서리, 눈 모양 준비 안내, 적용 영상 이미지 카드. 눈 렌즈는 실제 두 눈의 양끝 좌표·기울기로 그리며 얼굴이 없으면 표시하지 않음. 기존 감지 데이터와 판정에는 관여하지 않음.
- 경고 영상 재생 시 정차·휴식 안내를 상단에 표시. 기존 재생·종료·오류 처리는 유지.

## 검증

- 15개 파일, 114개 테스트 통과. 실제 눈 위치의 미러 좌표·기울기·빈 입력 처리 포함.
- TypeScript, 졸방 웹 빌드, Android `assembleDebug` 성공.
- 브라우저 390×844, 320×740, 844×390에서 촬영 안내와 계기판 겹침 없음, 가로 넘침 없음 확인.
- 실제 보유 영상 미리보기 재생 확인(`readyState=4`, 재생 시간 증가), 닫기 확인. 웹 광고 시도 후 잠금·기존 적용 영상 유지 확인.
- `prefers-reduced-motion: reduce`에서 준비 안내 눈·화면 진입의 animationName이 none인 것 확인. 검증 후 에뮬레이션 해제.
- HTTP·포트·웹/APK 주요 자산 및 신규 대표 이미지 11개 비교: `runtime-evidence.json` 참조.
- 실기기 카메라 위 렌즈 정렬, 실제 GPS, AdMob 보상 완료, 경고 중 화면은 이번 작업에서 실기 검증하지 않음. Android 설치본은 개발용 서명.
