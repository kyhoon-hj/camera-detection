# SIGN LOOP 2 — 핵심 표현 분류

## 구현 결과

20개 핵심 표현의 수집·검수·추론 계약을 구현했다. 실제 한국수어 동작 데이터와 모델 정확도는 아직 존재하지 않으며, 전문가 승인 전에는 학습 준비 완료로 표시하지 않는다.

## 신뢰도 정책

| 최고 후보 신뢰도 | 동작 |
|---|---|
| 0.85 이상 | `AUTO_SELECT`; 설정에 따라 TTS 전 확인 가능 |
| 0.60 이상 0.85 미만 | `SELECT_CANDIDATE`; Top 3 선택 요청 |
| 0.60 미만 | `RETAKE`; 재촬영 안내 |

ONNX KSL 추론 결과는 최고 후보를 기존 `RecognitionCandidate`로 유지하면서 `metadata.candidates`에 최대 3개의 코드, Gloss, 신뢰도를 내림차순으로 제공한다.

## 수집 승인 기준

- 표현별 최소 승인 샘플: 30
- 표현별 최소 승인 촬영자: 3명
- 세션 상태: `COMPLETE`
- 전문가 검수 상태: `metadata.reviewStatus=APPROVED`
- 20개 표현이 모두 기준을 만족해야 `trainingReady=true`
- 촬영자 단위 train/validation/test 분리

KSL 전용 세션 생성 시 등록된 표현만 허용하고 랜드마크 저장을 강제한다. 세션은 `PENDING` 검수 상태로 시작하며 동의 ID가 없으면 생성되지 않는다.
