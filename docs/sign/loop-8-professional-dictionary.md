# SIGN LOOP 8 — 전문 분야 사전과 후보 우선순위

## 구현 결과

기존 핵심 Gloss 20개와 별도로 전문 용어 26개를 추가하고, 통역 세션마다 `일반·공공·주차·병원·재난·교통·금융` 분야를 선택할 수 있게 했다. 선택 분야는 Gloss 인식 확률 자체를 조작하지 않고, 동일한 Gloss 시퀀스에서 생성되는 한국어 후보의 표현과 순위에만 적용한다.

전문 용어와 문장 규칙은 제품 동작을 위한 초안이며 농인 수어 사용자, 한국수어 통역사 및 각 분야 전문가의 승인을 아직 받지 않았다.

## 분야와 초기 용어

| 분야 | 주요 용어 |
|---|---|
| 공공기관 | 번호표, 민원, 서류 발급, 담당 부서, 본인 확인 |
| 병원·의료 | 통증 위치·강도, 증상 시작, 알레르기, 복용 약, 응급 여부 |
| 주차·키오스크 | 주차 요금, 정기권, 결제 오류와 기존 입차·출차·할인·차량 번호 |
| 재난·안전 | 대피, 구조 요청, 응급 여부와 기존 화재·경찰·구급차·위험·출구 |
| 교통 | 버스, 지하철, 정류장, 환승, 목적지 |
| 금융·결제 | 취소, 환불, 카드, 현금, 영수증, 본인 확인, 결제 오류 |

여러 분야에서 쓰이는 `본인 확인`, `결제 오류`, `응급 여부`는 하나의 용어가 복수 분야를 갖도록 정의했다. 각 전문 용어는 현재 `PENDING_EXPERT_REVIEW` 상태다.

## 분야별 후보 우선순위

예를 들어 `PAYMENT / ERROR` 시퀀스는 다음처럼 달라진다.

```text
주차 분야 1순위: 주차 요금 결제 중 오류가 발생했습니다.
금융 분야 1순위: 결제 오류를 확인해 주세요.
```

그 밖의 초기 분야 규칙:

- `HOSPITAL / WHERE` + 의료: 가까운 병원 위치 안내 우선
- `EXIT / WHERE` + 재난: 비상구·안전한 대피 출구 우선
- `EXIT / WHERE` + 교통: 교통시설 출구 위치 우선
- `HELP_NEEDED` + 의료: 의료진 도움 요청 우선
- `HELP_NEEDED` + 재난: 구조·긴급 도움 요청 우선
- `PAYMENT / DISCOUNT` + 주차: 주차 할인 적용 문장 우선

각 문장 후보의 `source`에는 `KSL_RULE_V1:{domain}`을 기록해 어떤 분야 규칙이 적용됐는지 확인할 수 있다. 분야 변경 시 기존 번역 후보를 폐기하고 같은 Gloss 시퀀스를 새 분야로 다시 번역한다.

## 고위험 분야 고지

의료·금융·재난은 `HIGH_STAKES`로 표시하며 모든 번역 응답에 다음 취지의 고지를 포함한다.

> AI 번역 결과이므로 중요한 결정은 전문 통역사 또는 담당자에게 확인해야 한다.

이 고지는 화면의 후보 위에 강조 표시한다. 분야 선택은 AI 결과를 전문가 판단으로 바꾸지 않는다.

## API

- `GET /v1/sign/professional-domains`: 분야, 한글 이름, 위험 수준, 전문 용어 수 조회.
- `GET /v1/sign/professional-dictionary?domain=medical`: 분야별 전문 용어 조회.
- `GET /v1/sign/translations/{sessionId}/domain`: 현재 번역 분야 조회.
- `PUT /v1/sign/translations/{sessionId}/domain`: 세션 분야 변경.
- `POST /v1/sign/translations/{sessionId}`: 선택 분야 우선순위로 다시 번역.

## 콘솔

수어 통역 TTS 패널에 전문 분야 선택을 추가했다. 분야 이름과 초기 전문 용어 수를 함께 표시하고, 선택 즉시 다음 번역 후보부터 새 우선순위를 적용한다. 의료·금융·재난에서는 고위험 AI 번역 고지가 후보와 함께 표시된다.
