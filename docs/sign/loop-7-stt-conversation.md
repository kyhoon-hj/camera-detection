# SIGN LOOP 7 — 음성 자막과 양방향 대화

## 구현 결과

비수어 사용자의 한국어 음성을 브라우저 STT로 인식해 큰 실시간 자막으로 표시하고, 확정된 문장만 세션 대화 메모리에 추가한다. 수어 사용자가 확정한 SIGN LOOP 5 번역도 같은 대화에 별도 발화자로 추가해 양방향 흐름을 구성한다.

```text
음성 사용자: 한국어 음성 -> 중간 STT 자막 -> 확정 문장
수어 사용자: 수어 -> Gloss -> 한국어 후보 확정 -> TTS
                                  ↓
                         시간순 대화 화면
```

## STT 동작

- 언어: `ko-KR`
- 연속 인식: 활성화
- 중간 결과: 큰 글씨 자막에 즉시 표시
- 확정 결과: `HEARING_USER / STT` 메시지로 세션에 추가
- 마이크 입력: 에코 제거, 잡음 억제, 자동 게인 요청
- 인식이 일시 종료되면 사용자가 중지하기 전까지 자동 재시작

Chrome Web Speech Recognition은 브라우저와 운영체제 구성에 따라 Chrome 음성 인식 서버를 사용할 수 있다. 따라서 네트워크 없이 항상 동작한다고 보장하지 않으며 화면에 이 제한을 명시한다. 서버는 마이크 오디오를 수신하거나 저장하지 않는다.

## 대화 메시지

| speaker | source | 의미 |
|---|---|---|
| `HEARING_USER` | `STT` | 비수어 사용자의 확정 음성 자막 |
| `KSL_USER` | `KSL_TRANSLATION` | 수어 사용자가 확정한 한국어 번역 |

각 메시지는 ID, 발화자, 문장, 생성 시각, 출처, 선택적 신뢰도와 클라이언트 중복 방지 ID를 가진다. 세션당 최근 100개로 제한하며 같은 `clientMessageId`는 한 번만 추가한다.

## API

- `GET /v1/sign/conversations/{sessionId}`: 시간순 대화 조회.
- `POST /v1/sign/conversations/{sessionId}/messages`: 확정 STT 또는 KSL 번역 문장 추가.
- `DELETE /v1/sign/conversations/{sessionId}`: 전체 대화 즉시 삭제.

## 화면

개발 콘솔의 양방향 대화 패널은 다음을 제공한다.

- 상대방 음성의 큰 실시간 자막
- 음성 듣기 시작·중지
- 음성 사용자와 수어 사용자의 좌우 구분
- 문장별 시각과 신뢰도
- 최신 문장 자동 스크롤
- 전체 대화 삭제
- STT 네트워크·개인정보 안내

수어 번역 후보를 확정하면 해당 문장이 `수어 사용자` 메시지로 자동 추가된다. 같은 번역을 다시 확정해도 번역 ID를 이용해 중복 저장하지 않는다.

## 개인정보와 삭제

- 중간 STT 문구는 브라우저 화면에만 있고 서버로 전송하지 않는다.
- 확정 텍스트만 현재 카메라 세션의 메모리에 둔다.
- 오디오·음성 파일은 서버에 저장하지 않는다.
- `전체 대화 삭제` 또는 카메라 중지 시 모든 대화 텍스트를 삭제한다.
- 서버 재시작 후 대화 내용은 복원되지 않는다.

- 발화자 구분과 문장별 시간: 완료
- 수어 번역 응답 연결: 완료
- 자동 스크롤과 전체 삭제: 완료

- 대화 문장 수정·오류 신고: SIGN LOOP 9
