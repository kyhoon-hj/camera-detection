# SIGN LOOP 11 — 오프라인 기본 동작

## 구현 결과 (2026-07-20)

네트워크 연결 없이 긴급 표현, 기본 문장, 제한된 분야 번역과 기기 TTS를 사용할 수 있는 버전 관리형 오프라인 패키지와 사용자 연결 설정을 구현했다.

## 오프라인 패키지

- 패키지: `suha-ksl-offline-core` v1.0.0
- 경량 엔진: `ksl-rule-lite-1.0.0` 내장 결정 규칙
- 긴급 표현 6개: 도움, 구급차, 화재, 위험, 경찰, 비상구
- 기본 문장 10개
- 지원 분야: 일반, 공공, 주차, 의료, 재난
- 한국어 번역: 로컬 결정 규칙
- 음성 출력: 브라우저/기기의 한국어 TTS
- 업데이트 정책: 사용자 명시 동의가 필요한 수동 업데이트

현재 패키지는 소프트웨어에 내장된 규칙 기반 경량 엔진이다. 별도 온라인 모델 다운로드 없이 시작할 수 있다. 실제 학습형 경량 ONNX 모델의 교체·롤백은 기존 모델 레지스트리 검증 절차를 사용해야 한다.

## 연결 설정

- `OFFLINE_ONLY`: 기본값. 온라인 확장을 차단한다.
- `AUTO`: 로컬 우선 모드다.
- `ONLINE_ALLOWED`: 사용자가 온라인 확장을 허용한다.

어떤 설정에서도 현재 SIGN 번역 경로는 `processingMode=OFFLINE`, `networkUsed=false`로 동작한다. `ONLINE_ALLOWED`는 향후 온라인 번역 공급자가 추가될 때 사용할 명시적 사용자 선택이며, 지금은 외부 전송을 시작하지 않는다.

## API

- `GET /v1/sign/offline/capabilities`
- `GET /v1/sign/offline/package`
- `GET /v1/sign/offline/{sessionId}/settings`
- `PUT /v1/sign/offline/{sessionId}/settings`

번역 응답에는 처리 모드, 네트워크 사용 여부, 오프라인 패키지 버전, 경량 엔진 버전을 포함한다. 카메라 세션 삭제 시 연결 설정도 삭제된다.

## 설정형 번역 위젯

수어 통역 모드에 브라우저 페이지 내 플로팅 번역 위젯을 추가했다.

- 표시/숨김
- 왼쪽 위, 오른쪽 위, 왼쪽 아래, 오른쪽 아래 위치
- 16–44px 글자 크기
- 55–100% 투명도
- Gloss 표시 여부
- 오프라인 상태와 패키지 버전 표시
- 브라우저 로컬 저장소에 설정 보존

이 위젯은 현재 개발 콘솔 페이지 내부 위젯이다. Windows 바탕화면 독립 위젯이나 다른 앱 위에 항상 표시하는 기능은 데스크톱 패키징과 OS 권한 처리가 필요한 별도 범위다.
