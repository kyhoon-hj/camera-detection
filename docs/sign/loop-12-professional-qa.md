# SIGN LOOP 12 — 전문 QA 매트릭스

## 구현 결과 (2026-07-20)

한국수어 인식의 주요 편향·환경 위험을 동일한 형식으로 기록하고 출시 준비 여부를 판단하는 영속 QA 매트릭스를 구현했다.

## 필수 시나리오

| 범주 | 필수 변이 태그 | 목적 |
|---|---|---|
| 왼손잡이 | `dominantHand` | 우세손 편향 확인 |
| 수어 속도 | `speed` | 빠름·보통·느림 구간 확인 |
| 조명 | `lighting` | 밝음·저조도·역광 확인 |
| 복잡한 배경 | `background` | 배경 간섭과 오인식 확인 |
| 손·얼굴 가림 | `occlusion` | 일시 가림 복구와 누락 확인 |
| 지역·연령 변이 | `region`, `ageGroup` | 표현 차이와 의미 보존 검수 |
| 긴급 표현 | `emergencyExpression` | 긴급 표현 Top 1 재현율 확인 |

각 결과는 정답 코드, 최대 3개 관측 후보, 올바른 후보 순위, 신뢰도, 처리 지연, 변이 태그, 전문가 의미 보존 판정과 메모를 보관한다. 영상과 랜드마크 자체는 QA 리포트에 저장하지 않는다.

## 판정 정책

- 일반 시나리오: 정답이 Top 3 이내, 신뢰도 0.60 이상, 지연 2,000ms 이하, 전문가 승인.
- 긴급 표현: 정답이 Top 1, 신뢰도 0.60 이상, 지연 1,200ms 이하, 전문가 승인.
- 합성 회귀 결과는 기능 검증에는 표시하지만 출시 준비 근거에서는 제외한다.
- 실제 사람·전문가 검수 결과가 7개 범주를 모두 통과해야 한다.
- 긴급 표현의 사람 검수 재현율은 0.95 이상이어야 한다.

따라서 자동 테스트가 모두 통과해도 실제 사람 자료가 없으면 `releaseReady=false`를 유지한다. 지역·연령 표현 차이는 코드 일치만으로 승인하지 않고 전문가의 의미 보존 확인을 필수로 한다.

## API와 콘솔

- `GET /v1/admin/sign/qa/scenarios`
- `GET /v1/admin/sign/qa/results`
- `POST /v1/admin/sign/qa/results`
- `GET /v1/admin/sign/qa/summary`
- `DELETE /v1/admin/sign/qa/results`

개발 콘솔의 `PROFESSIONAL KSL QA MATRIX` 패널에서 시나리오 선택, 변이 태그, 실제/합성 근거 구분, 후보·신뢰도·지연·전문가 판정을 기록하고 준비도와 최근 결과를 확인한다. 전체 삭제에는 사용자 확인을 요구한다. API는 현재 로컬 관리자 환경 전용이며 외부 배포 전 RBAC가 필요하다.
