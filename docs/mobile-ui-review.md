# SUHA Mobile UI 재검토

## 검토 결과 (2026-07-20)

기존 운전자 모바일 화면은 카메라, 상태, 세부 측정값, 보조 설정, 시작 버튼이 한 페이지에 연속 배치되어 작은 세로 화면에서 핵심 조작이 아래로 밀렸다. 운전 전 한 손 조작과 운전 중 빠른 상태 확인을 기준으로 정보 구조를 재편했다.

## 변경한 정보 구조

- `감지`: 카메라, 현재 상태, 한 문장 안내만 우선 표시한다.
- `상세`: 눈, 고개, 3D 자세와 신뢰도 등 기술 지표를 분리한다.
- `설정`: 경보음, 한국어 TTS 시험, 기준 재측정, 앱 설치, 개인정보 안내를 모은다.
- 하단 탭을 엄지 도달 영역에 고정한다.
- 시작·종료 버튼을 하단 탭 위에 고정해 모든 화면에서 즉시 접근할 수 있게 한다.
- 400px 이하 화면에서 여백과 카메라 모서리, 제목 크기를 축소한다.
- 기기 안전 영역(safe area)과 동작 줄이기 설정을 유지한다.

## 유지한 안전 동작

- 영상과 얼굴·자세 분석은 기기 안에서 처리한다.
- 앱이 백그라운드로 전환되면 카메라를 즉시 종료한다.
- 화면 방향 변경 시 감지를 종료한다.
- GPU 오류 시 CPU 호환 모드로 한 번 복구한다.
- 감지·자세·음성 로직은 변경하지 않고 화면 배치만 재구성했다.

## 검증

- 운전자 감지 단위 테스트 8개 통과
- TypeScript 및 Vite 생산 빌드 통과
- Android/iOS Capacitor 프로젝트에 새 웹 번들 동기화 완료
- Android APK는 JDK 17 설치가 운영체제 설치 단계에서 멈춰 생성하지 못했다. 기존 JDK 8은 현재 Android Gradle Plugin을 실행하기에 부족하다.
- 기존 Sites 프로젝트 ID가 현재 계정에서 조회되지 않아 웹 배포 갱신은 보류했다.
