# Wake Drive 작은 고개 숙임 오탐 조정

2026-09-10 · Android 0.1.10 / versionCode 11

## 문제와 변경

살짝 숙이는 동작에도 경고 영상이 나온다는 실기 제보에 따라 운전 모드의 고개 숙임 판정을 조정했다. 기존 코드에서는 작은 얼굴 비율 변화가 숙임으로 확정되고, 한번 확정된 뒤 부분적으로 고개를 들어도 낮은 유지 기준 때문에 감지가 계속되는 경우를 합성 랜드마크 테스트에서 재현했다.

기준 위치 대비 변화량을 사용하는 구조를 유지하고, 운전 모드에만 아래 값을 적용했다. 값은 랜드마크 정규화 비율이며 실제 고개 각도(도)가 아니다. 카메라·개인별 실제 허용 각도가 검증됐다는 의미도 아니다.

| 기준 | 이전 | 변경 |
|---|---|---|
| 얼굴 pitch 변화: 감지 시작 / 유지 | 0.09 / 0.065 | 0.15 / 0.12 |
| 어깨 정보 불충분 시 얼굴 단독 변화: 시작 / 유지 | 0.12 / 0.085 | 0.18 / 0.15 |
| 어깨 대비 머리 높이 감소: 시작 / 유지 | 0.12 / 0.08 | 0.18 / 0.14 |
| 숙임 후보 확인 시간 | 500ms | 800ms |

측면 촬영에 대한 추가 허용치와 어깨 신뢰도 검사는 유지한다. 숙임 조건을 벗어나면 후보 및 숙임 시간이 초기화된다. 확인 완료 후 지속 시간에는 후보 시작부터의 시간이 포함되므로 기존의 2초 카운트·2회 영상 및 4초 지속 시 영상 흐름은 그대로다. 눈 감김 판정과 열공/자세 모드 기준은 변경하지 않았다.

## 변경 위치

- [monitor.ts](../src/monitor.ts): DRIVER_HEAD_DOWN 상수, 운전 모드별 확정 시간 및 detectHeadDown 기준.
- [monitor.test.ts](../tests/monitor.test.ts): 오탐 및 복구 회귀 시나리오 8개 추가.
- [app/build.gradle](../native/jolbang/android/app/build.gradle): 설치본 버전 갱신.

## 검증

- 변경 전 신규 8개 테스트 중 7개 실패로 기존 동작 재현. 합성 입력이므로 사용자의 실제 얼굴 각도 재현으로 해석하지 않는다.
- 변경 후 전체 21개 파일 148개 테스트 통과. 작은 숙임 5초 유지, 얼굴 단독/어깨 동반 입력, 충분한 숙임의 2초·4초 동작, 부분 회복, 600ms 끄덕임, 재보정, 독립 눈 감김, 열공 기존 판정 확인.
- TypeScript 검사 및 Android APK 빌드 통과.
- 연결된 SM-F711N 업데이트 설치 성공. 설치 패키지 versionName 0.1.10 / versionCode 11 및 Activity 실행 성공 확인.
- 5210 웹 응답과 APK 내 배포 파일 일치 확인.
- 실제 얼굴 동작에 대한 개선 정도는 정차 상태에서 사용자 확인 필요. 합성 테스트와 빌드 결과로 실기 정확도를 대신하지 않는다.

## 실기 확인 순서

1. 0.1.10 설치본에서 휴대폰을 실제 사용할 위치에 고정한다.
2. 평소 정면 자세로 ‘기본 위치 설정’을 다시 완료한다.
3. 눈을 뜨고 살짝 숙였다 돌아왔을 때 숙임 카운트·경고 영상이 생기지 않는지 확인한다.
4. 충분히 숙이는 동작을 유지했을 때 숙임 시간과 기존 경고가 동작하는지 확인한다.
5. 고개를 다시 들었을 때 숙임 시간이 초기화되는지 확인한다. 얼굴 단독 화면과 어깨가 보이는 화면 모두 확인한다.

감도 조정은 작은 동작을 제외하는 대신 일부 숙임의 감지 시작을 늦출 수 있다. 현재 수치는 실기 비교가 필요한 초기 조정값이다. 추가 조정 시 경고를 끄는 방향으로 단순 완화하지 말고 작은 움직임 제외와 충분한 숙임 감지를 함께 검증한다. 원본 얼굴 영상이나 GPS 좌표를 Firebase에 추가 전송하지 않는다.
