# Korean Sign Language data license checklist

Complete this checklist before importing or training from an external dataset.

- [ ] The dataset was obtained by the user through the provider's official process.
- [ ] The exact dataset version and provider page were recorded.
- [ ] The dataset-specific terms permit the intended research, model training, and service use.
- [ ] Restrictions on commercial use and trained-model distribution were reviewed separately.
- [ ] AI Hub source videos and annotations will not be committed or redistributed.
- [ ] National Institute of Korean Language corpus terms were checked separately from report/publication licenses.
- [ ] Signer identity and other personal metadata will not be copied into the normalized dataset.
- [ ] The import command includes `--license-confirmed` and a meaningful `--license-reference`.
- [ ] Generated model documentation identifies the source, scope, limitations, and isolated-sign-only behavior.

The importer stores only normalized landmarks and external source references. It never downloads a dataset or copies source video into the repository.
